# 随身 AI 语音：小白完整使用教程

目标是：**按住 AI Passport 上键，对着设备说话，松开后电脑输入框出现文字；核对后短按确定键回车。**
教程以 Windows 10/11 x64 + 微信输入法为例。使用语音应用包里的 EXE，不需要 Python 或 ASR API Key。
想先让本地 Codex 帮忙，可复制 [GitHub 首页的配置指令](../README.md#codex-setup)，再按本文核对结果。

按顺序做：

1. [准备硬件、下载语音应用包](#prepare)
2. [刷好固件、完成设备配网](#network)
3. [运行 install.cmd，一键安装 VB-CABLE](#virtual-cable)
4. [安装并设置微信输入法](#wetype)
5. [在设置面板完成键位与音频配置](#mapping)
6. [使用其他语音输入法](#other-input-methods)
7. [启动托盘并连接设备](#start)
8. [完成第一次出字与按键测试](#first-test)
9. [收音检查、诊断与日常启动](#daily)

## 先理解四个部分

```text
AI Passport 麦克风
        │ 同一局域网 Wi-Fi
        ▼
电脑托盘程序（windows/start.cmd 启动，内含转发器与设置面板）
        ├─ 模拟语音快捷键 ──────────────► 输入法开始 / 结束识别
        └─ 设备的声音 → CABLE Input → CABLE Output → 输入法 → 输入框里的文字
```

**固件、电脑转发器、VB-CABLE、语音输入法都需要。** 固件让设备收音，转发器传声音与按键，
虚拟声卡把声音变成电脑可选择的麦克风，输入法把语音变成文字。
USB 用于供电/烧录，插着 USB 并不会自动出现 USB 麦克风；无需蓝牙配对。

## 1. 准备硬件和软件，下载语音应用包

### 1.1 需要的内容

| 内容 | 要求 / 下载入口 |
| --- | --- |
| AI Passport | FoloToy 同款 ESP32-C3 / 8 MB 硬件，安装包含随身语音的 Passport OS |
| 电脑 | Windows 10/11 x64；在“设置 → 系统 → 关于 → 系统类型”核对 |
| 语音应用包 | [GitHub Releases](https://github.com/ZDreamPY/folo-ai-passport-voice/releases) → 最近发布的 `ai-passport-voice-app-0.3.0.zip`（不含整机固件） |
| 虚拟声卡 | 无需手动下载：**windows/install.cmd** 自动从 [VB-CABLE 官方下载页](https://vb-audio.com/Cable/) 获取安装 |
| 微信输入法 | [微信输入法官网](https://z.weixin.qq.com/) → Windows 版 |
| 网络 | 设备接入 2.4 GHz Wi-Fi，电脑与设备在可互通的同一局域网 |

语音应用包不打包虚拟声卡驱动和输入法：VB-CABLE 由 `windows/install.cmd` 自动从官网下载安装，语音输入法需要自己安装。
电脑可以使用网线或路由器的 5 GHz Wi-Fi；设备只能接入支持的 2.4 GHz 网络。
macOS、Linux 和 ARM Windows 不在当前语音应用包的验收范围。

### 1.2 下载和解压

1. 打开 [下载页面](https://github.com/ZDreamPY/folo-ai-passport-voice/releases)，展开最近一次发布的 **Assets**。
2. 下载 **`ai-passport-voice-app-0.3.0.zip`** 语音应用包。旁边的 `.sha256` 用于校验，不要选择 Source code (zip)。
3. 右键 ZIP → **全部解压** → 选择一个以后不会随意移动的目录。
4. 打开解压目录里的 **`windows`** 文件夹。

| 文件 | 用途 |
| --- | --- |
| **`install.cmd`** | 首次使用先运行一次：自动安装 VB-CABLE 虚拟声卡和 Python 依赖 |
| **`start.cmd`** | 每天双击这个启动：托盘常驻并打开设置面板，不要单独拖出文件夹 |
| **`AI-Passport-Voice.exe`** | 主程序，start.cmd 会自动调用 |
| `diagnose.cmd` | 环境检查入口 |
| `voice-config.example.json` | 配置样例；设置面板保存时写回旁边的 voice-config.json |

**完成标志：windows 文件夹里同时有 start.cmd 和 AI-Passport-Voice.exe。**
不要直接在压缩软件里双击运行。想从桌面启动，可右键 start.cmd 创建快捷方式，再把快捷方式放到桌面。

如果只有 `.py`、没有 EXE，通常下载的是 GitHub 的 **Source code (zip)** 或克隆的源码。
小白用户回到 Assets 下载语音应用 ZIP；源码开发另看 [开发说明](DEVELOPMENT.zh-CN.md)。

## 2. 固件与设备配网

### 2.1 固件安装：已经刷好可以跳过

参考 [一机多能－口袋百宝箱玩法页面](https://ai-passport.folotoy.cn/plays/438/) 的安装指引，确认页面版本包含“随身语音”；尚未上传对应版本时先等待维护者更新。本 GitHub 应用包不含整机固件。
安装会替换设备当前玩法；需要本地烧录、备份或恢复的用户看 [固件附录](FIRMWARE.zh-CN.md)。
设备已能打开“随身语音”时，继续配网和电脑设置。

### 2.2 首次手机配网

1. 开机。设备没有已保存 Wi-Fi 时会进入手机配网/手机设置，屏幕显示设备热点名称。
2. 手机打开 Wi-Fi，连接屏幕上的 **`Passport-WiFi...`** 热点。
3. 如果手机提示“无互联网”，选择保留连接。没有自动打开页面时，浏览器输入 **http://192.168.4.1**。
4. 点页面上的 **“扫描附近 Wi-Fi”**，从列表直接点选自己路由器的 **2.4 GHz Wi-Fi**（也可手动输入名称），输入密码，提交配网。
5. 名字、个性签名、地址和名片等可在手机页面一起设置；先测试语音时也可后续再填。
6. 配网完成后设备接入路由器，正常进入应用。电脑也接入这个路由器。

已经存过可用 Wi-Fi 时，设备会尝试自动连接。更换网络时进入设备“设置 → 手机设置”。
设备热点用于设置，不是语音使用时的长期网络；配好后无需让手机或电脑一直连着设备热点。

**完成标志：设备联网，电脑与它在可互通的同一局域网。**
学校、公司和访客 Wi-Fi 可能隔离终端，同名网络也未必能互通；首次建议在自己家里的路由器上验证。

<a id="virtual-cable"></a>
## 3. 运行 install.cmd：一键安装 VB-CABLE 虚拟声卡

这一节的目标是两项：**装好 VB-CABLE 驱动，并把 Windows 麦克风切换为 CABLE Output。**
只安装驱动、仍选择笔记本/耳机麦克风时，输入法收到的不会是设备传来的声音。

### 3.1 双击 install.cmd 自动安装

1. 在解压出的 **windows** 文件夹里双击 **`install.cmd`**。
2. 脚本自动检测电脑是否已安装 VB-CABLE：已安装会提示跳过，直接进入依赖安装步骤。
3. 未安装时，脚本自动从 [VB-Audio 官网](https://vb-audio.com/Cable/) 下载官方驱动包，解压后以管理员身份启动 **`VBCABLE_Setup_x64.exe`**。Windows 弹出用户账户控制窗口时，核对后选择允许。
4. 在安装界面点击 **Install Driver**，等待完成。已安装时可能显示 **Remove Driver**；这时先取消，检查声卡是否已存在，不要为了继续教程去卸载。
5. 脚本随后自动安装转发器的 Python 依赖；电脑没有 Python 时会提示跳过——双击 EXE 使用不需要 Python，不影响本教程。
6. 保存其他工作，**重启电脑**，然后继续 3.2。

**装完必须做两件事：重启电脑；在语音输入法里把识别麦克风选为 CABLE Output。**
少做任何一件，设备声音都到不了输入法（输入法设置见第 4.3 节）。

自动安装失败（断网、官网地址变化等）时改用手动安装：
打开 [VB-CABLE 官方下载页](https://vb-audio.com/Cable/) 下载 Windows 驱动 ZIP → 右键 ZIP **全部解压**，保留安装程序旁边的驱动文件 → 右键 `VBCABLE_Setup_x64.exe` **以管理员身份运行** → Install Driver → 重启。
普通使用只需要 VB-CABLE，不需要 VoiceMeeter、A+B 或 C+D。
官网要求全部解压、管理员运行安装、安装后重启，见 [VB-CABLE 官方安装说明](https://vb-audio.com/Cable/)。

设置面板也会帮忙把关：启动转发器后，面板的“语音通道”区域检测不到 VB-CABLE 时会显示提示条，指回 `install.cmd` 和手动下载入口。

### 3.2 分清 Input 和 Output

| 名称 | 在 Windows 中是什么 | 本项目中的用途 |
| --- | --- | --- |
| **CABLE Input** | 播放设备 | 转发器把设备声音送进去 |
| **CABLE Output** | 录制设备，也就是可选的麦克风 | Windows / 输入法从这里读取声音 |

声音**进入 Input，从 Output 出来**；方向见 [VB-CABLE 官方说明](https://vb-audio.com/Cable/)。
设置面板的**音频输出设备**选择 **CABLE Input**，系统和输入法的麦克风选 **CABLE Output**。

### 3.3 必做：切换 Windows 默认输入

**Windows 11：**

1. 打开 **设置 → 系统 → 声音**。也可按 `Win + R`，输入 **`ms-settings:sound`**，回车。
2. 向下找到 **输入**，展开“选择用于讲话或录制的设备”。
3. 选中 **CABLE Output**，设备说明为 **VB-Audio Virtual Cable**，确认它成为默认输入。
4. 核对输入音量未静音。首次排查可从 100% 开始，不用增加麦克风增强。

**Windows 10：**

1. 打开 **设置 → 系统 → 声音**。
2. 在 **输入 → 选择输入设备** 中选择 **CABLE Output (VB-Audio Virtual Cable)**。

**完成标志：系统“输入”的当前设备是 CABLE Output。**
微软的设置路径见 [设置和测试麦克风](https://support.microsoft.com/zh-cn/windows/hardware/drivers/how-to-set-up-and-test-microphones-in-windows)。

“输出”区域保留平时的扬声器或耳机。把系统扬声器也改成 CABLE Input 会改变电脑正常声音的去向，配置本功能无需这样做。

### 3.4 同时核对默认通讯设备、启用状态和音量

1. 按 `Win + R`，输入 **`mmsys.cpl`**，回车。
2. 打开 **录制** 页，找到 **CABLE Output (VB-Audio Virtual Cable)**。
3. 右键 → **设为默认设备**；再右键 → **设为默认通讯设备**。已设置的项目可能不可点击。
4. 双击 CABLE Output → **级别**，确认未静音；首次排查可设为 100%。
5. **侦听** 页保持“侦听此设备”未勾选；默认格式先保留驱动原值。
6. 切换到 **播放** 页，确认 **CABLE Input** 存在并启用；默认播放设备仍为自己的扬声器/耳机。
7. 点击“应用 / 确定”保存。

找不到设备时，在列表空白处右键，勾选“显示禁用的设备”；如果 CABLE 被禁用，右键启用。
两端都不存在时检查是否安装并重启成功。

改默认输入会影响使用默认音源的会议/录音软件。开会可在会议软件里单独选实体麦克风，
或者暂时恢复系统默认输入；下次使用随身语音时选回 CABLE Output。

### 3.5 开启麦克风权限

- Windows 11：**设置 → 隐私和安全性 → 麦克风**。
- Windows 10：**设置 → 隐私 → 麦克风**。

确认麦克风访问开启，允许应用访问麦克风，并开启 **允许桌面应用访问麦克风**。
使用 Windows 录音工具检查时，也要给它相应权限。权限不代替默认输入设备选择，两项都要完成。
见 [微软麦克风问题排查](https://support.microsoft.com/zh-cn/windows/hardware/drivers/fix-microphone-problems)。

### 3.6 本节核对表

| 检查项 | 应看到的结果 |
| --- | --- |
| 驱动存在并已重启 | 播放页有 CABLE Input，录制页有 CABLE Output |
| 默认输入 / 默认通讯输入 | CABLE Output |
| 默认播放 | 平时的扬声器或耳机 |
| 麦克风权限 | 输入法等桌面应用可以访问 |

现在还没启动设备传音，CABLE Output 电平不动是正常的。
电脑转发器启动、设备按住上键后才会把设备声音送入虚拟麦克风。

## 4. 安装与设置微信输入法

### 4.1 从官网安装并切换到微信输入法

1. 打开 [微信输入法官网](https://z.weixin.qq.com/)，选择 **Windows 版**，下载安装程序。
2. 打开安装程序，按界面提示安装；如果提示重启或注销，保存工作后照提示完成。
3. 打开记事本，点击空白编辑区，让输入光标出现。
4. 按 **`Win + Space`**，选择微信输入法；也可点击任务栏右下角的输入法标识切换。
5. 找到微信输入法的设置入口：通常可通过输入法状态栏的设置图标或任务栏/托盘右键菜单打开。
   如果入口名称不同，通过开始菜单搜索“微信输入法”，打开对应的设置入口。

官网提供 Windows 安装入口。语音设置的位置与选项名称可能随版本变化，以下按设置内容定位。

### 4.2 启用语音，确认键位与触发方式

1. 在输入法设置中找到 **语音输入 / 语音 / 快捷键** 相关页面。
2. 启用语音功能。首次如弹出麦克风访问或联网提示，按输入法说明完成。
3. 找到语音快捷键设置，选择并记下 **左 Shift / 右 Shift / 该版本实际允许的键**。
4. 找到语音触发方式，确认是 **长按/按住说话**，还是 **点击开始、再次点击结束**。
5. 保存设置，回到记事本；**先用电脑实体键盘试一次**。
   按住型应能按住开始、松开结束；点击型应能用同一个快捷键点击开始、再次点击结束。

推荐先用输入法支持的 **Shift + 按住说话** 模式跑通。
输入法如果只允许左右 Shift，就在这些选项中选择；程序支持 F9 并不表示微信输入法一定允许把语音设为 F9。

**完成标志：电脑键盘的语音快捷键能打开并结束输入法语音界面。**
此时 CABLE Output 还没收到设备声音，手动按键后没有文字不代表快捷键设置失败。
若连语音界面都打不开，先解决输入法启用、键位和输入焦点，再设置设备映射。

### 4.3 确认输入法用的是 CABLE Output

1. 再次核对 Windows 默认输入为 **CABLE Output**。
2. 微信输入法如果提供独立麦克风选择，也选 **CABLE Output (VB-Audio Virtual Cable)**。
3. 没有独立音源选择时，让它跟随已切换的系统默认输入。
4. 换过音源后结束并重新开启语音；如果仍沿用旧音源，重启输入法，必要时重启电脑。

在设置面板更换音频输出设备不会自动切换 Windows 或输入法麦克风。
输入法的联网、登录、识别语言等要求以该软件为准；普通话、方言等识别设置需要与你说话的语言匹配。

## 5. 在设置面板完成键位与音频配置

设备上键不是直接运行微信输入法，而是让托盘程序模拟你配置的电脑快捷键。
所以**输入法的键位 + 模式**与**设置面板里的热键 + 触发方式**必须对应。

### 5.1 hold 和 tap 有什么区别

| 输入法如何操作 | 面板触发方式 | 设备按住上键时 | 设备松开上键时 |
| --- | --- | --- | --- |
| 按住快捷键说话，松开结束 | **hold（按住说话）** | 按下并保持电脑快捷键 | 释放电脑快捷键 |
| 点击同一快捷键开始，再次点击结束 | **tap（点按开始/再点结束）** | 点击一次电脑快捷键 | 再点击一次同一快捷键 |

**两种模式在设备上都按住上键说话、松开结束。** tap 改变的是电脑端动作，不是让你在设备上点一下后一直录音。
只有输入法确实支持同一快捷键切换开始/结束，才适合 tap。
如果开始和结束是两个不同快捷键，或必须用鼠标结束，当前配置不能完整自动适配。

### 5.2 打开设置面板，核对热键

1. 双击 **windows/start.cmd**。托盘出现程序图标，浏览器自动打开设置面板 **http://127.0.0.1:38765**；没有自动打开时，在浏览器手动输入该地址。
2. 核对面板“语音热键”里显示的热键和触发方式。点击热键录入框后直接按组合键即可重新录制，点“默认”恢复出厂热键。
3. 面板里改完点击**保存设置**即热生效：转发器即时换用新键位、新声卡，不用重启；改动设备 IP 或 UDP 端口时会自动重建连接。

### 5.3 例子：改为左 Shift 按住说话

1. **先在微信输入法设置里改成左 Shift + 按住说话**，再用电脑键盘验证。
2. 打开设置面板，在“语音热键”的录入框里按下键盘**左 Shift**，“触发方式”选 **hold（按住说话）**。
3. 确认“语音通道”的**音频输出设备**是 **CABLE Input**。
4. 点击**保存设置**。用设备按住上键试一次，电脑应出现输入法语音界面。

想改回右 Shift 时，在面板重新录制右 Shift 并保存；输入法那边同步修改。
输入法是点击切换模式时，触发方式选 **tap**。

### 5.4 按键动作：确定键发送、下键切窗

面板的**按键动作**配置设备另外两个键在电脑端触发的键位，同样是点击录入框后按键录制：

| 设备键 | 面板项 | 默认电脑动作 | 用途 |
| --- | --- | --- | --- |
| 确定键（OK 键） | OK 键（发送） | **Enter** | 核对文字后回车/发送 |
| 下键 | 下键（切窗） | **Alt + Tab** | 切换电脑窗口 |

**切窗迟滞**（默认 1000 毫秒，可填 100–3000）：首点切窗后在该时长内再按下键可多选窗口，停手后完成切换。
觉得切窗太难停下就调大，觉得反应慢就调小。
下键会真的切换电脑窗口，不要在演示、全屏游戏或未保存的窗口前随意按。

### 5.5 面板配置项一览

| 面板区域 | 配置项 | 作用与建议 |
| --- | --- | --- |
| 语音热键 | 热键 + 触发方式 | 设备上键模拟的快捷键，与输入法设置一致 |
| 按键动作 | OK 键（发送）、下键（切窗）、切窗迟滞 | 另外两个设备键注入的键位与切窗节奏 |
| 设备连接 | 设备 IP、UDP 端口 | IP 留空用广播发现；端口保持默认 **33333**，设备与电脑要对应 |
| 语音通道 | 音频输出设备 | 选 **CABLE Input**；未检测到 VB-CABLE 时这里会提示先运行 install.cmd |
| 启动 | 开机自动启动 | 勾选后开机自动常驻托盘并启动转发器 |

支持单键和 `Ctrl+Shift+空格` 这类组合键；组合键用面板直接录制即可，不必手写键名。
程序不支持 `Fn` 或“一串先后按下的快捷键”。避免选择会与常用应用冲突的键；
输入法必须能设成并正确响应相同快捷键，才算可用。

配置实际保存在 EXE 旁的 **voice-config.json**，面板保存时自动写回。
习惯手动编辑 JSON 的高级用户也可以用记事本改这个文件，保存后同样热重载；
写错 JSON 可能整项不生效，普通用户建议只用面板。

### 5.6 修改后没生效怎么办

1. 面板保存后配置即时生效；如果没生效，先确认点过**保存设置**，再看面板显示的热键/触发方式是否已是新值。
2. 核对输入法那边也保存了相同设置，并再次用实体键盘确认。
3. 手动改过 voice-config.json 的：检查文件名、UTF-8 编码和 JSON 语法；读取失败时程序可能退回默认设置。
4. 改了设备 IP 或 UDP 端口后面板会重建连接；设备端也要使用相同端口。
5. 仍不生效时点面板“启动”区的**重启转发器**按钮，或退出托盘后重新双击 start.cmd。

需要命令检查时，在 windows 文件夹空白处右键“在终端中打开”，使用 PowerShell：

```powershell
# 校验当前配置 JSON；正常会显示配置对象，报错则先修复
Get-Content -LiteralPath .\voice-config.json -Raw -Encoding UTF8 | ConvertFrom-Json -ErrorAction Stop

# 只列出键名或声卡，然后退出
.\AI-Passport-Voice.exe --list-keys
.\AI-Passport-Voice.exe --list-devices
```

普通用户双击 start.cmd、在面板里点选即可，不必使用命令行。

<a id="other-input-methods"></a>
## 6. 也可以使用其他语音输入法

不限定微信输入法。想尝试讯飞、搜狗或其他带语音功能的软件，先从**该软件官网**安装，再核对下面三项：

1. 能在电脑文本框中输出识别文字。
2. 能选择 **CABLE Output**，或能跟随已设为 CABLE Output 的系统默认麦克风。
3. 支持**按住一个快捷键说话，松开结束**，或**同一快捷键点击开始/再次点击结束**。

先用电脑实体键盘验证开始和结束，再在设置面板录入同一键位、选择对应的 hold/tap，保存后即生效。
不能只看“软件有语音输入”就认定按键适配；不同软件及版本尚需你在本机验证。

例如某输入法允许 **F9 点击开始/再次点击结束**，就在面板把热键录成 F9、触发方式选 tap。
这是适配方法，**不是对某款输入法默认 F9 的说明**。

Windows 自带语音输入可用 **Win + H** 打开，转发器也能模拟 `win+h`。
但微软的启动快捷键说明不保证“再按 Win + H 就结束”；不能把它直接当成已验证的 tap 方案。
如果本机需要点击麦克风按钮结束，就仍需手动完成结束动作。
系统语音输入需要联网、可用麦克风和文本输入框，见 [微软语音输入说明](https://support.microsoft.com/en-us/accessibility/windows/use-voice-typing-to-talk-instead-of-type-on-your-pc)。

<a id="start"></a>
## 7. 启动托盘，连接设备

1. 双击 **windows/start.cmd**，托盘常驻即可，无需保持任何窗口。只运行一个托盘程序。
2. 首次若出现 Windows 防火墙提示，在自己信任的**专用网络**允许该程序通信；无需关闭防火墙。
3. 设备联网后进入 **随身语音 / 随身 AI 语音**；页面标题可能显示 **AI语音输入**。
4. 打开设置面板 http://127.0.0.1:38765，确认热键、触发方式与你选择的一致，音频输出为 **CABLE Input**。
5. 等待设备显示“按住上键说话”“可以说话了”等可说话提示。

**完成标志：电脑音频路由就绪，设备可以说话，没有“麦克风通道未就绪”提示。**
“电脑已连接”只证明网络心跳到达；就绪也不证明输入法已经选对麦克风，还要做下一节。

如果托盘没有出现或直接退出，在 windows 文件夹打开终端，运行 `cmd /k start.cmd` 保留错误信息，再运行 diagnose.cmd。
程序是社区发布的未签名 EXE，下载时核对 GitHub 来源与包旁的校验文件；不必关闭安全软件。

<a id="first-test"></a>
## 8. 在记事本完成第一次出字与按键测试

先用记事本，避免第一次试按键就把未经核对的文字发到聊天对象。

1. 打开记事本，新建空白文档，点击输入区域，确认光标正在闪烁。
2. 切换到已配置的语音输入法。
3. **按住设备上键，不松开。**
4. 等电脑语音界面出现，再对着**设备麦克风**说：

   > 今天下午三点开会，请带上笔记本。

5. 说完松开上键，等待识别完成。设备应恢复待机提示。
6. 查看文字是否出现在记事本，内容是否清楚完整。
7. 核对后，**短按设备的确定键（OK 键）**。记事本应换行。

| 要验证的内容 | 成功结果 |
| --- | --- |
| 上键映射 | 按住设备上键，电脑输入法开始语音 |
| 设备收音 | 对着设备说话，输入框出现对应文字 |
| 结束动作 | 松开上键后结束本次识别 |
| 确定键回车 | 识别完成后短按确定键，记事本换行 |

确定键默认发送的是 **Enter**，聊天软件设置成“回车发送”时才能用于发消息。
下键默认模拟 **Alt + Tab** 切换电脑窗口，不是回车键；不要把它当确认用。
先松开上键、等文字出现，再按键；录音期间按键不会发送。
输入光标必须还在目标框里，设备不会自动判断识别是否正确或选择发送对象。

<a id="daily"></a>
## 9. 收音检查、环境诊断和日常启动

### 9.1 确认声音来自设备，而不是电脑麦克风

1. 保持托盘运行（设备停在随身语音就绪页面）。
2. `Win + R` → `mmsys.cpl` → **录制**，观察 CABLE Output 旁的电平条。
3. **按住设备上键，对着设备说话**，电平应变化。没按上键时不动是正常的。
4. 想听声音质量，打开 Windows **录音机 / 声音录制器**。
5. 录音工具有音源选项时选 **CABLE Output**；没有入口时确认系统默认输入是它，再重新打开录音工具。
6. 开始录音，按住设备上键说一小段，松开，再停止录音；用扬声器/耳机回放。

录音仅需保存在自己电脑里，不用上传。测试时上键仍会触发输入法快捷键；若输入法窗口遮住录音工具，可先把录音工具准备好再按键。
**清楚完整的录音 + 实际出字**比单看就绪或电平更能说明流程跑通。

| 听到的情况 | 下一步 |
| --- | --- |
| 无声 | 检查录音音源、CABLE Input 路由、设备是否真的按住上键传音 |
| 很小、破音或断续 | 检查设备麦克风遮挡、距离、环境噪声、Wi-Fi；不要盲目拉满增益 |
| 清楚完整但错字多 | 核对输入法音源、识别语言、联网和识别服务；与实体麦克风同一句话作对照 |
| 容易漏开头 | 等输入法语音界面出现再说，不要按键同时开始第一句话 |

### 9.2 使用诊断工具

双击 **windows/diagnose.cmd**，它检查快捷键语法、声卡端点/格式和 UDP 33333 端口。
它不录音、不模拟按键，也不结束其他进程。
自己的转发器开着时端口可能显示 **BUSY**；先退出托盘再诊断，避免把正常占用当成错误。

Codex 或终端中不想等待“按任意键”时，用 EXE 入口：

```powershell
.\AI-Passport-Voice.exe --diagnose
```

诊断不能确认 Windows 当前默认输入、输入法实际音源、设备音频到达或识别出字。
所以即使结果全是 OK，也要完成第 8 节。更多情况看 [故障排查](TROUBLESHOOTING.zh-CN.md)。

### 9.3 配好以后每天只做这些

1. 电脑双击 **start.cmd**（开启过开机自启则免）；托盘常驻即在工作。
2. 设备联网，进入 **随身语音**，等到可以说话。
3. 电脑选中目标输入框，按住上键 → 等语音界面 → 说话 → 松开 → 核对 → 确定键回车。

如果为会议换过麦克风，记得先把输入法音源/系统默认输入选回 **CABLE Output**。
驱动与快捷键通常不需要每天重新安装或设置。退出托盘即停止服务；设备长按确定可退出语音页面。

使用可信局域网，不做公网端口映射；语音传输目前没有加密或身份认证。
输入法如何联网和处理语音由其服务决定。源码运行等进阶操作看 [开发说明](DEVELOPMENT.zh-CN.md)。
