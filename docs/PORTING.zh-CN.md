# 设备模块接入边界

`device/main/apps/voice/` 是 Voice 设备端业务源码快照，并非可独立刷写的整机。除该目录外，不提供维护者整机的入口、启动器、设置、字体或硬件实现。

## 可直接复用的层

- `app_types.h`、`app_state.c/.h`：纯事件/动作状态机。按键事件包括按下、松开、短按；保持状态机与实际按键时序一致。
- `adpcm.c/.h`：音频编码；电脑端有对应解码实现。
- `app_protocol.c/.h`：设备/电脑 JSON 协议。`voice.start`、`voice.end`、`key.action` 与电脑端就绪状态需要成对处理。
- `udp_audio.c/.h`：ESP-IDF/lwIP 的局域网传输；`audio_streamer.c/.h` 管理录音缓存和工作任务。

## 宿主需要提供的接口

| 源码中的外部头文件/模块 | 由你的宿主工程提供 |
| --- | --- |
| `bsp_audio.h` | 音频初始化、采样格式、读写 PCM、音量与关闭；16 kHz / 16 bit / 单声道录音 |
| `bsp_display.h`、`bsp_battery.h`、`bsp_button.h` | LVGL 显示、背光/休眠、电池读数与实际按键 |
| `apps/app_base.h`、`launcher/app_registry.h` | 应用描述符、启动/停止/按键入口和退出请求；实现应属于你的宿主 |
| `app_fonts.h`、`ui_pixel.h` 等共享 UI 头文件 | 选择自己的字体和 UI helper，或改写 `app_ui.c` 为你的界面 |
| ESP-IDF / FreeRTOS / lwIP / NVS / LVGL | 使用对应依赖的公开接口与许可证，不从本仓库寻找整机实现 |

该表说明接口职责，不是虚假的完整 ABI 头文件。源码中的函数调用及类型是移植时需要实现/替换的具体清单；编译器提示未找到这些头文件属于宿主尚未接入，不是下载遗漏。接口细节由你的板级实现决定。

## 资源与验证顺序

先完成 Wi-Fi 与音频驱动，再在应用进入时初始化 Voice，会话停止时等待工作任务退出后释放。不得在任务仍使用缓存时强制释放；退出后不要保留麦克风或界面对象。按住、松开、重复事件、断网、电脑关闭、再进入至少分别测试。

当前仓库保证纯逻辑 host 测试和 Windows 程序可独立验证，不保证用户自定义宿主已完成全设备编译或音质验收。普通用户无需移植，使用官网已集成的固件即可。
